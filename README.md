# chutools

This is a collection of tools for working with audio assets in Nintendo games that use JAudio. It is effectively an updated version of [JAMTools](https://www.xayr.gay/tools/SoundModdingToolkit/) by XAYRGA.

Development will primarily focus on features to aid [Dusklight](https://twilitrealm.dev/) modding, though we will do our best to accept contributions relevant to other games as well.
